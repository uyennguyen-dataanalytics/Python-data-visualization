# Data Visualization with Python

This project explores the fundamentals of data visualization using Python, with a focus on Matplotlib, Pandas, and Streamlit. It demonstrates how to clean, analyze, and visualize data through various charts and plots to uncover patterns, trends, and insights. 

Matplotlib and Pandas are used to create visualizations and perform basic data analysis, while Streamlit is used to build [interactive dashboard] (https://dashboard-ae.streamlit.app/). 

The project aims to develop practical skills in presenting data effectively and making data-driven insights easier to understand.
